## 📋 Workflow Structure

**Node 1 — Webhook Trigger**
- Listens for incoming POST requests
- Accepts: name, email, company, message
- Triggers instantly on form submission

**Node 2 — Google Sheets**
- Appends new row automatically
- Saves: Name, Email, Company, Message
- Real-time lead database, always up to date

**Node 3 — Gmail**
- Sends personalized HTML welcome email
- Uses lead's name and details dynamically
- Delivered instantly after form submission
